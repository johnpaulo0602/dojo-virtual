# Component References for Student Wizard & Profile

## Components to use

- **Dialog Calendar** — Calendar with month/year selector in dialog (day-react-picker + shadcn Select)
- **Combobox pesquisavel** — Command + Popover pattern for searchable dropdowns (cities, states, schools)
- **Dropzone** — FileUpload from diceui for boletim/comprovante uploads (max 5MB, PDF/JPG/PNG)
- **Input with validation** — Error state with AlertCircle icon and destructive text
- **Input masks** — CPF, WhatsApp, CNPJ formatting
